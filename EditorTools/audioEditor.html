◈ ARIVE 音訊編輯器 — 完整功能說明

套用範圍規則

有選取範圍 所有效果與工作流只作用於選取範圍。選取外完全不受影響。
沒有選取 效果作用於整段音訊（與舊版行為相同）。
重新取樣 選取範圍會被替換成重新取樣後的樣本，長度改變、選取範圍自動更新。

一鍵工作流

槍聲處理 移除 DC → 正規化 → 輕度壓縮 → 淡出。
遠處槍聲 低通 + 小殘響 + 輕壓縮。
腳步聲循環 移除 DC → 修剪靜音 → 循環接縫 → 正規化 → 雜訊閘。
爆炸處理 移除 DC → 正規化 → 壓縮 → 軟削波 → 淡出。
對講機 帶通 → 軟削波 → 位元壓碎 → 高通。
水下效果 低通 → 混響 → 顫音。
恐怖怪物 重新取樣（-5）→ 混響 → 軟削波 → 立體聲加寬。
老舊錄音 高通 → 軟削波 → 位元壓碎 → 回聲。
機械化 顫音 → 軟削波 → 立體聲加寬。
通用清理 移除 DC → 修剪靜音 → 爆音修復 → 正規化 → 淡出。

效果對話框

快速預設集 每個效果提供 3–6 個預設參數，一鍵套用。
我的預設集 調整好參數後輸入名稱、按「儲存」，即可重複使用。
試聽 套用前先聽效果，不會修改檔案。
